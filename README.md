# Наши мультвселенные

Личная коллекция из 15 живых фотографий. Статический сайт: распознавание изображений происходит на устройстве посетителя, фотографии с его камеры на сервер не отправляются.

## Как пользоваться

1. Открыть сайт в Safari или современном браузере.
2. Нажать **Оживить фотографию** и разрешить камеру.
3. Навести камеру на рисунок на напечатанной карточке, сохраняя его целиком в кадре. Для печати лучше матовая бумага и ровное освещение.
4. Камера распознает одну из 15 фотографий и показывает её анимацию. Короткие анимации без звука. Общий ролик с музыкой открывается отдельной кнопкой.

Если камера недоступна или распознавание затруднено, нажать фотографию в коллекции: откроется тот же ролик.

## Состав

- Корневая папка — готовый статический сайт, без сборки и серверной части.
- `assets/photos/` — 15 фотографий для распознавания.
- `assets/clips/` — соответствующие анимации.
- `assets/targets.mind` — заранее скомпилированные данные распознавания всех фотографий, в том же порядке, что и `scenes.json`.
- `assets/our-multiverse.mp4` — общий ролик, 51 секунда, с непрерывной музыкой.
- `assets/print-originals.zip` — оригиналы изображений для печати.
- `vendor/` — локальные закреплённые версии MindAR 1.2.5 и Three.js 0.160.0, вместе с их лицензиями. Внешние CDN не требуются.

Камера работает на HTTPS или localhost. GitHub Pages предоставляет HTTPS. Для загрузки файлов и первого просмотра нужен интернет. Сайт и файлы публичны; файл robots запрещает индексацию добросовестным поисковым роботам, но не служит защитой доступа.

## Карточки для печати

В папке `print/` находятся PDF-файлы 10×15 см: 15 лицевых сторон с белой рамкой и один общий оборот с QR-кодом. QR-код указывает на `https://sgswizzy.github.io/AR_photo_love_ekaterina/`. Перед печатью убедиться, что сайт опубликован по этому адресу. Печатать в масштабе 100% с сохранением белых полей; оборот одинаков для всех карточек. Доступны отдельные PNG, SVG и PDF QR-кода.

## Размещение

Для GitHub Pages загрузить содержимое `` в корень публичного репозитория, затем выбрать **Deploy from a branch → main → /(root)**. `.nojekyll` отключает обработку Jekyll. Платные API, генерация видео во время просмотра и сервер не используются.

Лимиты и условия бесплатного размещения определяет GitHub. Сохранить архив репозитория и доступ к аккаунту. При печати QR-кода использовать окончательный адрес опубликованного сайта и сохранять его.

## Проверки

Проверены загрузка 15 карточек, воспроизведение каждого клипа и общего ролика, мобильная вёрстка и запуск распознавания через синтетическую камеру. Эти проверки не заменяют проверку физических отпечатков на iPhone.

Материалы личной коллекции не лицензируются как свободные. Лицензии сторонних библиотек расположены в `vendor/`. Музыкальное сопровождение: Noize MC — «Вселенная бесконечна?».
